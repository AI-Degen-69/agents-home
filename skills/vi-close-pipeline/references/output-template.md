# Hebrew Chat Output Contract (חובת דיווח בעברית) — `vi-close-pipeline`

Local-only operator template. Never published — the sync strips the pointer block
in `SKILL.md` and never copies this file.

```markdown
# 🏁 Close Pipeline — Station VI: [#<id> - <כותרת>](<url-issue>)

## 📁 מצב התיקייה:
ענף: `main` | נקי | מסונכרן | ענפים ישנים: אין

## ✅ בדיקות ו-GitHub:
- GitHub: PR [#<n>](<url-pr>) מוזג, [#<id>](<url-issue>) [נסגר / נסגר עכשיו]

[בעיה מקורית בשפה פשוטה]
```

## תבנית חסומה — כשה-Clean Exit Gate לא עבר

**משתמשים בתבנית הזו רק כשהסגירה נכשלה.** אין להציג את התיקייה כנקייה ואין
להציע `/i-pick-issue` — הפער הזה הוא ההבדל בין סגירה לחסימה.

```markdown
# ⛔ Close Pipeline — Station VI: [#<id> - <כותרת>](<url-issue>) — **חסום**

## 📁 מצב התיקייה:
ענף: `[main / feature / כלום]` | **לא נקי** | [לא מסונכרן / לא ידוע]

## ⛔ מה חסם (אחד לכל פריט, עם הפקודה והפלט):
- **[שם הבדיקה]** — `[הפקודה שרצה]` → `[הפלט האמיתי, מילולי]`
  - ניקוי: **דרוש** → `[הפעולה שתבהר את זה]`
  - בעלים: `[תחנה / אדם]`

## ✅ מה כבר הושלם:
- PR מוזג / הבעיה נסגרה / ניקוי `[X קבצים]` — `[מה קרה בפועל]`

## ❓ מה צריך עכשיו:
[הפעולה הבאה — בעל אחד ברור]
```

**חובה בתבנית החסומה:**
- לפחות פריט חסימה אחד, עם הפקודה שרצה והפלט האמיתי (לא תמיד «הכול עבר בהצלחה»).
- אין להציג את התיקייה כנקייה, ואין להציע `/i-pick-issue`.
- אין לצרוף `git add -A`, לדחוף בכוח, או למחוק ענפים — הכל נשאר נשמר לבעל.
