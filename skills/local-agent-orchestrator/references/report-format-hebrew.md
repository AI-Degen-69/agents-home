# Hebrew report shape (חובת דיווח בעברית)

Operator template. Short, three parts. No approval line, no explanation of the skill.

```markdown
# 🧭 <שורת מצב אחת>

**איפה:** `<repo root>` על ענף `<branch>` — <מלפנים/מאחור, נקי/מלוכלך>
**עבודה:** <קישורי משימה או PR, או "אין">
**מצאתי:** <מה הבדיקות הראו, 1-2 שורות>

---

## ➡️ <הצעד הבא היחיד>

<משפט אחד שממנה את הפעולה>

**הרצה:** `<תיקייה>`, ענף `<branch>`, סשן <חדש|זהה>, `<מודל>`
**למה המודל הזה:** <שורה אחת: סוג המשימה, ציון, מכסה>

---

<בלוק פרומפט, רק כשהצעד הבא הוא פרומפט>
```

## כללים

- ציינו קובץ רק כשהוא משנה את ההחלטה. רשימת כל השינויים מסתירה את התשובה.
- כשלשינויים אין מקור, הדוח נעצר ב"מצאתי" עם השאלה.
- כששני מסלולים מתאימים, כתבו את שניהם במשפט אחד והמליצו על הבטוח.
- סשן חדש ובחירת מודל בשורה אחת. בלי הסברים ארוכים.
- כתבו דוח שחורג משלושת החלקים כקובץ HTML עצמאי עם `dir="rtl"`, לפי חוק 8 בחוזה הגלובלי. בשיחה השאירו שורה אחת עם קישור.
- הפרומפט מסתיר את התזמור: בלי אזכור מתכנן, סקיל או שיחה קודמת.
