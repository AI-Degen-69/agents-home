איך בודקים שזה עובד אצלך

שתי דקות, בתוך החלון שלך. אין מה להתקין.

  1. פתח חלון סוכן חדש בתיקיית הפרויקט. זה החלון שבו אתה עובד בדרך כלל — לא קובץ תצוגה.
  2. שאל: ״where were we״ הכישור אמור להיכנס לפעולה, לקרוא את המצב, ולהחזיר דוח קצר.
  3. בדוק שהדוח בנוי משלושה חלקים: שורה אחת של מצב → קישורי עבודה או ״אין״ → שורת Found קצרה. ואחריה צעד אחד מומלץ. לא רשימת קבצים, לא פלט פקודות.
  4. בדוק את מקרה העצירה: שים קובץ שלא שייך לשום משימה. הוא חייב לעצור ולשאול שאלה אחת — ״של מי העבודה הזאת?״ — ולא לנתב לפי גודל, ולא לגעת בקובץ.
  5. אם רוצים לראות את הקלט הגולמי מאחורי הדוח: node skills/local-agent-orchestrator/scripts/repo-triage.js תראה כותרת Forensic Repository Triage, ואחריה עץ עבודה, ענפים, worktrees, stashes ו-PRs פתוחים.

אם פקודת gh נכשלת, הדוח יכתוב שורת WARN ולא יציג ״אפס PRs פתוחים״ כברירת מחדל. זו השאלה שהכי קל לטעות בה — והיא עכשיו גלויה.
