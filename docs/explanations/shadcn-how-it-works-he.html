איך shadcn עובד באמת?

זו לא ספרייה רגילה שמתקינים עם npm. זה מאגר מתכונים + כלי שמעתיק קוד לתוך הפרויקט שלך. הקובץ components.json הוא תעודת הזהות שאומרת לכלי איפה להדביק ואיך לכתוב.

1. הרעיון הגדול: אתה מקבל את הקוד, לא תלות

❌ ספרייה רגילה

אתה עושה npm install lib והקוד נשאר בחוץ. אם הספרייה נשברת — אתה תקוע. אם אתה רוצה לשנות עיצוב — קשה.

✅ shadcn

אתה עושה npx shadcn add button והקוד של הכפתור נוחת אצלך בתיקייה components/ui. שלך לגמרי. תשנה מה שאתה רוצה.

משפט אחד לזכור: shadcn = חנות מתכונים. ה־CLI הוא השליח. components.json הוא הכתובת שלך.

2. מה זה components.json? תעודת הזהות של הפרויקט

בלי הקובץ הזה הכלי לא יודע כלום: איפה לשים קבצים, איזה React, איזה Tailwind, איזה אייקונים. איתו — כל פקודה עובדת אוטומטית.

// דוגמה אמיתית + הסבר לכל שורה
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "nova",          // איך זה נראה
  "tailwind": {
    "version": "v4",      // v4 = קובץ CSS, v3 = tailwind.config.js
    "css": "app/globals.css" // איפה הצבעים שלך
  },
  "aliases": {
    "components": "@/components", // קיצור ליבוא
    "ui": "@/components/ui",     // כאן נוחתים הכפתורים
    "utils": "@/lib/utils"
  },
  "iconLibrary": "lucide",  // lucide או tabler — לא לערבב!
  "base": "radix",         // radix או base-ui — קובע API
  "registries": {
    "@shadcn": "built-in"
  }
}

השדות שהכי מבלבלים — בפשטות

שדהמה זה אומר בפשטותאם טועים
aliases.uiלאן להדביק את הקודיבוא נשבר, קבצים הולכים לאיבוד
base: radix / baseאיזה מנוע מאחורי הקלעיםקוד עם asChild לא עובד ב־base ולהפך
tailwind v3 / v4איפה הצבעים גריםעיצוב לא נטען, מסך לבן
iconLibraryמאיפה האייקוניםשגיאת lucide-react not found
registriesאילו חנויות מותרותהחיפוש לא מוצא כלום

5. למה 3 הפרויקטים שלך עוד לא מוכנים?

פרויקטמה יש היוםמה חסר ל־shadcn
crypto-spreadשרת Python בלבדאין React, אין Tailwind, אין components.json — צריך תיקיית front חדשה
spread-hunterExpress + HTML פשוט ב־dashboard/staticצריך לעבור ל־Vite React + npx shadcn init

שורה תחתונה: MCP מחובר אצלך, Skill טעון, אבל בלי components.json באף פרויקט — אין לאן להדביק. זו הסיבה ששום add לא יעבוד כרגע.

6. איך להרוויח מ־MCP + Skill בפרונט?

  • Skill = חוקים. מונע טעויות: צבעים סמנטיים, gap במקום space-y, כותרת חובה בחלונית, אייקון עם data-icon.
  • MCP = ידיים. מחפש, מציג קוד מלא, נותן פקודת התקנה. לא מנחש API.
  • יחד: אתה אומר "מצא לי טבלת מחירים" → אני מחפש → מראה דוגמה → נותן add → בודק audit.
